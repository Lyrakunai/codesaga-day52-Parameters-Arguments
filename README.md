## What I Learned Today 🧠
- Parameters are defined in a function definition, while arguments are supplied during a function call.
- Positional arguments are mapped according to parameter position.
- Keyword arguments are mapped using parameter names.
- Positional and keyword arguments can be combined when Python's ordering rules are followed.
- Positional-only and keyword-only parameters can intentionally restrict how a function is called.
- Parameter and argument matching must satisfy the function's defined interface.
